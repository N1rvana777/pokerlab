# 产品与交付边界

权威完整需求：[Codex_Poker_Solver_Prompt.md](../Codex_Poker_Solver_Prompt.md)。
本文件仅记录当前实现决策，不复制全部需求。

- 本地优先，用于离桌复盘。核心工作流：选玩家 → 叠加特质 → 一键完整策略 →
  冻结对手 → 跨分支、跨街回应 → 逐组合 EV 与敏感性。
- 两人 Flop/Turn/River 是主线，先真实 CPU 求解与独立验算，再完善界面。
- Equilibrium 的精度为两人最佳回应收益提升平均值；Fixed 的精度是 Hero 回应差距。
  Constrained 是独立后续模式。不能把固定对手收益贴成 GTO 精度。
- 默认不新增未来抽水，当前 pot 已反映过去的扣除。现场抽水未核实。
- 首版原型保守预算 2–4 GiB，长期 32GB 机器目标 20–24 GiB，再按当前可用内存下调。
  小型 Flop 验收成绩不能证明日常宽范围 Flop 已达到几分钟目标。
- 参数是研究假设。中文 UI、可编辑组合预设、手动覆盖、undo/redo、范围网格、
  节点导航、逐行动 EV、模型敏感性仍是完整产品要求，未因原型限制而删除。
- 不做翻前均衡、云端账号、收费资源或大型神经网络训练。云预算 $50/月不构成授权。
- 三人里程碑：小型 River，固定两名对手，枚举校验；再处理不同筹码、边池、
  联合牌张排斥和 Turn/Flop。三人均衡另行研究，不套用两人收敛保证。
- 结构化 CLI 先于 MCP；当前未安装 MCP，也未接入模型 API 或任何登录令牌。
