# Pokerstudio 本地架构

## 进程与数据

`python -m pokerstudio.server` 启动 127.0.0.1:8770 的本地 Python 服务，静态中文界面位于 `web/`。选择这一方案，是因为现有 Pokerlab 已有 Python 服务与 WSL 原生任务接口，可以复用而无需迁移 solver。原工作台 8765 和 CLI 保持原入口。

`project.py` 是非破坏编辑状态：项目保存原素材路径和 probe 元数据，片段只记录素材 in/out。片段按数组顺序形成连续项目时间，手牌/行动/发牌事件/字幕/说明使用项目秒。裁切整手牌会重新映射相交轨道。普通重排不会猜测用户希望如何移动手牌标记；编辑后应检查标记范围。所有重要编辑先深拷贝、验证再提交，最多 100 步内存撤销；重新打开项目恢复当前状态，撤销历史不跨重启。

项目 JSON 原子保存，编辑自动保存。`last_project.json` 用于启动恢复，已有不同另存文件不覆盖。缺失素材仍可打开项目并重新定位。`audit` 保留最近 200 次操作来源；撤销/重做保留追踪记录。没有修改、删除、重编码原素材。

默认 `.data/` 保存项目、导入副本、预览缓存、代理、测试素材、导出、agent 会话；`--data-dir` 可更换。`.tools/` 保存应用媒体工具。它们已列入 `pokerstudio/.gitignore`。凭据由 agent 独立认证目录管理，不写入项目或导出文件。

## 媒体

浏览器原视频通过支持 Range 的 `/media/<id>` 按需读取。暂停合成画面与播放时透明叠加由媒体模块渲染，导出也从同一时间/叠加计划生成。原素材路径仅在本地后端使用，不把长视频加载到 Python 内存。帧缓存按项目 id、修订号和时间区分；代理与导出是后台任务。

`tasks.py` 管理排队/运行/成功/失败/取消，工作进程须完整 wait/reap。取消请求不是成功终态。`media.py` 用 FFprobe 探测、FFmpeg 剪切拼接与 CPU 编码；准确功能及实测以 MEDIA.md/ACCEPTANCE.md 为准。

## Solver

`solver.py` 复用 `pokerlab.solver.server.Jobs`，通过其既有跨进程锁、资源预算与 WSL worker 调用真实引擎。用户提供完整配置，或从两人街开始手牌严格映射。不会把多人视频记牌转换成伪单挑结果；不会将 dollar 自动转换成整数筹码。中途行动状态、缺少范围/公共牌/单位等均拒绝并明确提示。

报告保留输入审计、根 EV 定义、计算条件和测得精度。求解结果绑定提交时的手牌，手牌修改会标记过期。`analysis` 字段只能由真实 solver 完成报告写入，UI/agent 不能人工伪造。Node Lock、对手特质和尺寸沿用现有配置，不修改引擎。

## Agent 与两个入口

`agent/` 是可复用基础层：正式 Codex app-server 订阅 provider 与独立 OpenAI Responses API provider。认证、会话恢复、流式事件、工具参数验证、取消/错误由它管理。业务能力只通过 `tools.py` 的真实工具执行。

剪辑入口 context 带项目 id，切换项目后旧会话不能修改新项目。独立 `/analysis` 入口保存分析配置和分析会话；其工具不能编辑/导出剪辑项目。两入口共享 provider，不共享业务状态。现有 Pokerlab 工作台可链接该入口，但依然独立运行。

子目录外的必要修改为现有 `src/pokerlab/solver/web/index.html` 头部加入 8770 `/analysis` 链接，以及根 README 加入 Pokerstudio 启动/文档入口；需要同时启动 Pokerstudio。没有迁移或改写 solver 服务。自定义 Pokerstudio 端口时直接打开对应 `/analysis` URL。

工具与 UI 共用项目验证、实际求解、后台导出和自动保存。AI 只解释确认的数据，EV/频率必须来自完成的真实报告。模型候选与真实请求验证状态分开，订阅限额不会触发付费 API 回退。

## 本地边界

HTTP 只监听回环，检查 Host、Origin 和 Sec-Fetch-Site，修改请求要求本页面的随机令牌。静态路由固定白名单，媒体仅从当前项目素材和应用导出目录读取；没有通用任意文件下载 API。API key 由后端管理，错误脱敏，不记录请求内容或认证代码。

这是本人电脑上的本地首版。自动视觉识牌、多人 solver、多人共享个人订阅、远程托管、独立口播轨/背景音乐和商业接入不包含在当前实现中。
